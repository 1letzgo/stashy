abstand

Audiobooks and podcasts, side by side

Native Audiobookshelf client for iPhone. Open source, no paywall, no “pro” tier.

Beta viaTestFlight Source onGitHub
  • Free
  • Open source (MIT)
  • No tracking
  • CarPlay

abstand is a native iOS and iPadOS client for your self-hosted Audiobookshelf server. A hobby build, not a polished product – it runs against our own server and keeps improving whenever there is time.

What it does

One app for both libraries

Two libraries at once

One book library and one podcast library, no juggling separate clients.

Playback

Chapters, sleep timer, playback speed.

CarPlay

Keep listening in the car, straight from the dashboard.

Downloads

Offline listening with progress sync back to the server.

Ebooks

EPUB and PDF reading via the Readium toolkit.

Server admin

Podcast subscribe via RSS and other basic management.

Status: beta

Beta via TestFlight, or build it yourself from source. Requirements: an Audiobookshelf server you can reach.

If you run Audiobookshelf with separate book and podcast libraries, feedback is welcome – especially what is missing compared to the web app.
