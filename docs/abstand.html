abstand

Native Audiobookshelf client for iPhone. Audiobooks and podcasts side by side, open source, no paywall.

TestFlight GitHub

abstand is a native iOS and iPadOS client for your self-hosted Audiobookshelf server. A hobby build, not a polished product — it runs against my own server and keeps improving whenever there is time.

What it does

  • Two libraries at once: one book library and one podcast library, no juggling separate clients.
  • Playback: chapters, sleep timer, playback speed, CarPlay.
  • Downloads: offline listening with progress sync back to the server.
  • Ebooks: EPUB and PDF reading via the Readium toolkit.
  • Server admin: podcast subscribe via RSS and other basic management.
  • Fully open source: MIT licensed, no subscription, no “pro” tier.

Status

Beta via TestFlight, or build it yourself from source. Requirements: an Audiobookshelf server you can reach.

If you run Audiobookshelf with separate book and podcast libraries, feedback is welcome — especially what is missing compared to the web app.
